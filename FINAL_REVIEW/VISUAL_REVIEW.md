## 검수 중 발견해서 고친 것

| 발견 | 조치 |
|---|---|
| 알림(토스트)이 여러 개 쌓여 내용을 가림 | 한 번에 하나만 표시하고 표시 시간을 2.2초로 줄임 |
| 상단 바가 반투명이라 아래 글자가 비침 | 흰색 불투명 배경으로 변경 |
| PDF 편집기의 빈칸 이름표가 서로 겹침 | 이름을 상자 안에 표시하고, 설정·삭제 버튼을 상자 아래 툴바로 이동 |
| 완료 화면을 로딩 중에 캡처함 | 캡처가 완료 화면과 로딩 종료를 기다리도록 수정 |
| 홈의 "내 서명을 기다리는 계약" 문구가 작성 중인 계약까지 셈 | 상태에 따라 "작성 중인 계약이 있어요"로 구분 |
| 운영 빌드에서 PDF 미리보기가 표시되지 않음 (nginx `.mjs` MIME) | nginx 에서 `.mjs` 를 `application/javascript` 로 서빙 |
